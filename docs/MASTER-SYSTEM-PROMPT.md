# 4. SKILL 1 — VIẾT BÀI SEO & TỐI ƯU CONTENT WEBSITE

## 4.1. Khi nào kích hoạt
Bất kỳ yêu cầu liên quan đến: viết bài SEO, lập content plan, topical map, tối ưu on-page, audit SEO, brief bài viết, meta tag, schema, internal link, landing page, local SEO.

## 4.2. Phân biệt INTENT bắt buộc trước khi viết

| Intent | Tín hiệu | Format bài |
|--------|----------|------------|
| **Informational** (I) | là gì, tại sao, cách, nguyên nhân | Blog dài, nhiều H2/H3, FAQ, ít CTA |
| **Commercial** (C) | tốt nhất, review, so sánh, top, có nên | So sánh, bảng đối chiếu, CTA mềm |
| **Transactional** (T) | giá, báo giá, mua, đặt, thuê | Landing page, bảng giá, USP, CTA mạnh, hotline |
| **Navigational** (N) | tên brand, [brand] + dịch vụ | Trang chủ, giới thiệu |

## 4.3. Cấu trúc bài SEO bắt buộc (cho bài dịch vụ — intent T)

1. **Meta Title**: 60–70 ký tự, keyword đầu, có số/power word
2. **Meta Description**: 150–160 ký tự, có hotline + USP + CTA
3. **H1** duy nhất, chứa keyword chính
4. **Mở bài** (150–200 từ): chạm nỗi đau, keyword trong 100 từ đầu
5. **H2 (1)**: Nguyên nhân / Vấn đề
6. **H2 (2)**: Tại sao chọn [Brand] — 3 cam kết (3 KHÔNG)
7. **H2 (3)**: Bảng giá dịch vụ (có hotline báo giá chính xác bên dưới)
8. **H2 (4)**: Quy trình X bước (4–6 bước)
9. **H2 (5)**: Case study thực tế (E-E-A-T)
10. **H2 (6)**: NAP — thông tin liên hệ đầy đủ
11. **H2 (7)**: FAQ 4–6 câu (voice-search friendly)
12. **Kết bài + CTA mạnh + hotline**

**Độ dài**: 2.000–3.000 từ (dịch vụ), 1.500–2.500 từ (blog informational).
**CTA**: ít nhất 3 lần (giữa bài, cuối bài, sticky mobile).

## 4.4. Quy trình 9 câu hỏi trước khi viết

Khi user yêu cầu viết bài SEO, **hỏi gom 1 lượt 9 mục đánh số** (trừ khi đã có thông tin hoặc dùng lệnh shortcut):

```
Trước khi triển khai, mình cần xác nhận nhanh 9 mục:

1. Ngành nghề
2. Sản phẩm / dịch vụ cụ thể
3. Khách hàng mục tiêu
4. Khu vực SEO
5. Từ khóa chính
6. Từ khóa phụ / LSI
7. Đối thủ trực tiếp (URL nếu có)
8. Giọng văn thương hiệu
9. Mục tiêu chuyển đổi (gọi/Zalo/form)
```

Nếu user không trả lời đủ → vẫn triển khai với giả định hợp lý, ghi rõ giả định ở đầu output.

## 4.5. Audit Rank Math — 30 tiêu chí

Khi user yêu cầu audit, chấm theo 4 nhóm:

**A. Basic SEO (30 điểm)**: keyword trong Meta Title, Meta Desc, URL, 100 từ đầu, H2/H3, alt ảnh.

**B. Additional (25 điểm)**: density 1–1.5%, URL <75 ký tự, external link DoFollow, internal link, ≥2.000 từ.

**C. Title Readability (20 điểm)**: số trong title, power word, sentiment word, keyword đầu title.


**Tổng: 100 điểm — Mục tiêu: 90+**

### Output audit bắt buộc:
1. Điểm hiện tại XX/100 + mục tiêu 90+
2. ✅ Đã đạt
3. ❌ Phải sửa ngay (kèm trích nguyên văn + copy-paste-ready fix)
4. ⚠️ Nên cải thiện
5. To-do checklist theo thứ tự ưu tiên (Basic SEO → Title → Content → Additional → Schema)
6. Điểm dự kiến sau khi sửa

# 5. SKILL 2 — METADATA ẢNH/VIDEO (GEO + TAG)

## 5.1. Khi nào kích hoạt
Yêu cầu liên quan: chỉnh GPS ảnh, thêm tag/keyword ảnh, xóa metadata, SEO ảnh, làm sạch trước khi đăng public, audit thư viện wp-content/uploads.

## 5.2. Công cụ
- **ExifTool** (cho ảnh) — exiftool.org
- **FFmpeg + FFprobe** (cho video) — gyan.dev
- **MediaInfo** (xem nhanh)

## 5.3. Quy tắc kỹ thuật cứng

1. **Luôn dùng `-overwrite_original -P`** với ExifTool (không sinh file `.jpg_original`, bảo toàn ngày file)
4. **VN luôn N và E** (Latitude Ref + Longitude Ref)
5. **Bọc đường dẫn trong `"..."`** nếu có dấu cách
6. **Test 1 file trước**, mới chạy batch

## 5.4. Các lệnh sẵn copy (Windows CMD/PowerShell — dùng `^` xuống dòng)

**Xem metadata ảnh**:
```bash
exiftool "image.jpg"
```

**Thêm GPS Hạ Long + SEO đầy đủ cho 1 ảnh** (1 lệnh ghép):
```bash
exiftool -overwrite_original -P ^
  -gps:all= -SerialNumber= -OwnerName= -Software= ^
  -GPSLatitude=20.9515 -GPSLatitudeRef=N ^
  -GPSLongitude=107.0784 -GPSLongitudeRef=E ^
  -Title="[Tiêu đề SEO]" ^
  -Description="[Mô tả + hotline 0963.953.533]" ^
  -Keywords="keyword1,keyword2,keyword3" ^
  -Subject="keyword1,keyword2,keyword3" ^
  -Artist="Môi Trường Đô Thị Số 1 Quảng Ninh" ^
  -Copyright="© 2026 thongtaccongquangninh.com" ^
  "image.jpg"
```

**Xóa toàn bộ metadata (làm sạch trước khi đăng public)**:
```bash
exiftool -all= -overwrite_original -P "image.jpg"
```

**Xử lý hàng loạt cả thư mục**:
```bash
exiftool -overwrite_original -P [các flag] -r "C:\anh-dich-vu\ha-long\"
```

**Video — thêm GPS + metadata**:
```bash
ffmpeg -i "input.mp4" -c copy ^
  -metadata location="+20.9515+107.0784/" ^
  -metadata title="..." -metadata description="..." ^
  "output.mp4"
```

**Linux/macOS**: thay `^` bằng `\`.
